# Ready or Not - Weapons from Tarkov

Standalone weapon mods for Ready or Not. Download complete weapon ZIP packages from Releases. Each ZIP includes its weapon PAK.

Latest collection includes NL545 GP and DI (original reload animations), Radian Model 1, MDR 5.56 and 7.62, MCX SPEAR FDE and Black, Wedge MP7A1 primary and secondary variants, QBZ-191, AK-12, SA-58 BEL, RSh-12 and Saiga-12K FA.

Install the selected PAK into ReadyOrNot/Content/Paks after removing older versions of the same mod.

Latest does not mean every change has passed in-game testing. MCX canted sight, MP7 secondary shield support, and recent Saiga buckshot changes remain subject to verification. RSh-12 and Saiga-12K FA were designated v1.0 releases by the author; packaging checks are not in-game testing.
